# Doom Fire Algorithm

## 📌 Overview
JavaScript implementation of the classic Doom Fire algorithm, recreating the fire effect in real time.

## 🎯 Purpose
Explore algorithmic logic, matrix manipulation and dynamic visual rendering.

## 🛠️ Tech Stack
- JavaScript
- HTML
- CSS

## 📚 What this project demonstrates
- Visual algorithms
- Array and matrix manipulation
- Real-time rendering
